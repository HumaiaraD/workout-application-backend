# workout-application-backend
# Workout API
A Flask API for recording workouts and exercises. Each workout can include multiple exercises, with sets, reps, or duration stored on the WorkoutExercises join record.
# About
This workout app lets users create workouts and exercises, connect exercises to workouts, and track sets, reps, and duration. I built the API with Flask, used SQLAlchemy for the database, Marshmallow for handling data, and Flask-Migrate for database changes.
